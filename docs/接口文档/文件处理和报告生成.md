## 1. 大模型文件解析接口

**接口路径：** `/llm/analysis`  
**请求方法：** `POST`  
**功能说明：** 提交文件进行大模型解析，支持多维度业务参数配置

### 请求参数说明

| 参数 | 类型 | 说明 | 必填 |
|------|------|------|------|
| businessType | String | 业务类型标识，固定值："file" | 是 |
| params | Array | 请求参数列表，最多 32 项（项目兼容单项与多项；多项时按顺序串行处理） | 是 |

> 项目兼容扩展说明：`/llm/analysis` 支持 `mhtml`/`mht` 文件；服务端下载后会先提取正文文本，再复用现有大模型解析流程。
>
> 整个 JSON 请求体最大 64 MiB；超限同步返回 HTTP `413`。`params` 中任一项格式或领域树无效时同步返回 HTTP `400`，整批不建任务、不下载文件。

### params参数结构

| 字段 | 类型 | 说明 | 示例值 |
|------|------|------|--------|
| architectureList | Array | 完整领域树；请求结构不变，服务端在本地召回有界模型候选，但完整树仍用于合法性校验、数据标准判断、存储归并和 callback | 见下方示例 |
| architectureStandardList | Array | 数据标准额外解析范围；最终分类命中该范围或其子孙节点时，回调 `fileDataItem` 额外返回数据标准字段 | `[{"id":1768464916588441,"name":"国家军用标准"}]` |
| channel | Array | 资料来源机构候选列表（字典编码）；服务端仅使用请求提供的候选，不注入默认候选。未传、传空数组或没有有效候选对象时，模型和回调均输出空字符串 | `[{"value":"装发","key":"02"}]` |
| country | Array | 国家列表（范围）（字典编码） | `[{"value":"美国","key":"02"}]` |
| fileName | String | 文件对象名（业务主键） | `"bded228dc94440519d87f97cfb6b520b.pdf"` |
| originalFileName | String | 业务原始文件名，服务端保留请求原值；除辅助大模型理解文件主题外，还作为后续知识谱系回调来源展示名 | `"GJB 9001C-2017 质量管理体系要求.pdf"` |
| filePath | String | 文件下载地址（格式 application/octet-stream） | `"http://localhost:8080/file-download/..."` |
| format | Array | 原生格式列表（范围）（字典编码） | `[{"value":"文档类","key":"03"}]` |
| maturity | Array | 成熟度列表（范围）（字典编码） | `[{"value":"阶段成果","key":"02"}]` |
| security | Array | 密级列表（范围）（字典编码）；解析时根据文档开头内容判断密级，未见相关说明则默认为“公开” | `[{"value":"公开","key":"02"}]` |

### architectureList元素结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 领域体系唯一标识；兼容正数字符串，拒绝布尔值、非正数和重复 ID |
| name | String | 领域名称 |
| parentId | Long | 父节点 id；根节点可为 `0`、空或不传，请求子集缺少父节点时按有限树边界处理 |
| path | String | 从根节点到当前节点的 id 链 |
| pathName | String | 节点语义路径；非空值按不透明文本使用，不根据 `/` 反推树层级 |
| remark | String | 可选的节点名词概述；非空时用于召回和辅助模型理解节点含义 |

甲方正式调用继续在每个 `params[]` 中传完整 `architectureList`，无需在调用侧预先裁剪候选。服务端从完整树建立索引和 Top-K 候选；请求与 callback 的字段结构均未因此改变。

领域树输入边界：

- 单个 `architectureList` 最多 10,000 个节点，可见深度最多 128 层。
- `name`、`path`、`pathName`、`remark` 分别最多 256、2,048、2,048、4,096 字符；四个文本字段累计最多 2,000,000 字符。
- 包含调用方扩展字段在内的紧凑 JSON 最多 4,000,000 字符；非 JSON 可序列化值、重复 ID、非法父节点或父链成环均会被拒绝。
- 为兼容存量调用，`architectureList` 缺失、为 `null` 或空数组时继续使用服务端默认树；显式提供非空列表时，每个节点都必须合法，服务端不再静默过滤坏节点。

### architectureStandardList元素结构

`architectureStandardList` 使用与 `architectureList` 相同的节点结构和资源上限。该列表表示需要额外解析数据标准字段的分类范围，可以只传部分节点，也可以传包含“数据标准”树根节点的完整节点列表；缺失、`null` 或空数组表示不启用扩展字段。

领域分类规则：

- 默认 `topk_two_stage` 模式先根据文件名、原始文件名、标题、型号/标准号及有界正文片段，在完整树上执行 exact、字符 BM25、树路由和业务规则召回；AnythingLLM 标签向量召回不在本轮范围。
- 当 `architectureList` 只有一个合法节点时，服务端直接确定该节点 `id`，跳过分类并以字段抽取作为首次模型查询；其他信息提取仍正常执行。
- 当 `architectureList` 包含多个节点时，服务端先执行纯领域分类，再在同一文档 Session 的全新独立 Thread 中执行字段抽取，防止分类回答进入字段抽取上下文。抽取 Prompt 不包含完整领域树，只携带已确认 ID、语义路径和节点类型。
- 模型可见候选不超过 128 个，分类 Prompt 不超过 32,000 字符。分类与抽取阶段各最多执行 2 次实际模型查询，供应商重试和 repair 共享阶段预算，单文件总上限为 4 次。
- 多候选优先分类到证据充分的叶子节点。叶子证据不足时，只能从模型可见候选中选择最深的可靠父节点；该父节点必须属于完整树、深度至少为 2 且满足召回资格。完整树的八个根节点及“数据标准”父节点禁止返回。
- 分类返回空值、非数字、候选外 ID 或其他非法结果时，只在分类阶段剩余预算内使用完全相同的候选执行有限 repair；不得扩大候选或回退到完整树 Prompt。
- 当最终分类名称严格符合 `*-基础数据`、`*-战技指标`、`*-运用数据` 或 `*-效能数据` 时，回调中的 `data.architectureId` 仍返回该具体子分类 ID；服务端内部知识库统一按对应的武器装备父节点 ID 存储。该内部归并不会改变本接口的回调结构和分类结果。
- 当文档内容明确为 GJB、国军标、国家军用标准相关资料时，`architectureId` 只允许返回模型可见候选中“数据标准”分支下的六类叶子之一，禁止返回“数据标准”父节点；兜底按完整 `architectureList` 的原始顺序选择可见叶子。
- 当最终 `architectureId` 命中 `architectureStandardList` 范围或其子孙节点时，回调 `fileDataItem` 额外返回 `militaryName`、`num`、`startTime`、`implTime`、`approvalDept`；未命中时不返回这 5 个字段。
- `architectureStandardList` 仅控制上述五个扩展字段，不替代完整 `architectureList`，也不改变领域分类候选。
- 无有效召回信号、候选或 Prompt 超过合同上限，或者分类及有限 repair 后仍无法确定合法 ID 时，文件任务进入 `status=3`；服务端禁止默认返回 ID `1`，不会发送成功 callback，也不会写入永久知识库。

运行与审计说明：

- `DOCSENSE_ANALYSIS_CLASSIFICATION_MODE=topk_two_stage` 为默认两阶段模式。
- `topk_single` 保留 Top-K 有界候选，但回滚为单阶段分类与字段抽取。
- `legacy` 仅允许完整树候选不超过 128 且最终完整 Prompt 不超过 32,000 字符的小树；任一上限超出时任务失败，不允许无界发送完整领域树。
- `DOCSENSE_ANALYSIS_FILENAME_CONSTRAINT_MODE=scope_guard` 为默认文件名约束模式，启用简氏作用域识别，以及 `originalFileName` 与首页真实标题的双源分支约束；设置为 `legacy` 可即时回滚到既有文件名硬约束。文件名不能在证据冲突或不足时单独决定最终分类；显式空值或未知值会使服务拒绝启动。
- `DOCSENSE_ANALYSIS_IDENTITY_RESELECT_MODE=enforce` 为默认装备身份受限重选模式。仅当描述性 `originalFileName` 与文档开头/标题独立确认同一唯一装备型号、并且完整的装备父节点与七类直属明细叶子均可见时，才允许对落在目标分支外或过粗祖先上的初次分类执行一次受限重选；空值、越界结果或调用失败均保留初次分类。设置为 `shadow` 可只记录而不采纳重选结果，设置为 `off` 可即时关闭。
- 服务端按任务 execution 幂等保存 tree fingerprint、query digest、Top-64、最终候选、通道排名、RRF、protected 原因、Prompt 字符数、返回 ID/rank、耗时及失败阶段。召回审计不保存正文；审计失败时不会创建远端 RAG Session。
- 以上改造只改变内部候选与模型调用流程，不改变请求或 callback shape。在人工 gold set 和上线门禁通过前，不据此宣称生产分类准确率已经提升。

`score` 评分规则：

- 闭源渠道或权威机构公开发布，如军政官方机构网站或正式出版物，评分 `95`。
- 专业科研单位，如兰德、简氏等知名智库及装备研制单位等，评分 `85`。
- 专业信息网站，如海上舰艇交通网、美舰艇历史与部署网、海军学院新闻网、防务新闻网等，评分 `75`。
- 普通信息网站，如综合性新闻网、百度百科等，评分 `65`。
- 未明确数据来源的资料，评分 `55`。

          "key": "02"
        }
      ],
      "country": [
        {
          "value": "美国",
          "key": "02"
        }
      ],
      "fileName": "bded228dc94440519d87f97cfb6b520b.pdf",
      "originalFileName": "GJB 9001C-2017 质量管理体系要求.pdf",
      "filePath": "http://localhost:8080/file-download/bded228dc94440519d87f97cfb6b520b.pdf",

> 项目兼容扩展说明：除单文件请求外，也支持 `params` 中放入多个文件对象；后端会按数组顺序逐个处理，并为每个 `fileName` 分别维护状态、进度和回调。
>
> 同名文件已有 `status=0/1` 任务时返回 HTTP `409`。任务已进入业务终态但首次回调仍为 `callback_status=pending` 时也暂不接受同名重跑，避免覆盖尚未送达或尚未确认的旧结果；`failed` 任务通过 `/llm/check-task` 实际补发时会持有有界发送租约，租约释放前同样返回 `409`。回调成功、失败或明确跳过且没有在途补发后可再次提交；交接窗口中断时可先调用 `/llm/check-task` 完成补发或状态迁移，过期租约会由后续补发安全接管。

## 2. 大模型报告生成接口

**接口路径：** `/llm/generate-report`  
**请求方法：** `POST`  
**功能说明：** 基于多文件内容生成结构化分析报告

### 请求参数说明

| 参数 | 类型 | 说明 | 必填 |
|------|------|------|------|
| businessType | String | 业务类型标识，固定值："report" | 是 |
| params | Array | 请求参数列表（仅使用第一个元素） | 是 |

> 项目兼容扩展说明：`/llm/generate-report` 的 `filePathList` 可包含 `mhtml`/`mht` 文件；服务端下载后会先提取正文文本，再参与报告生成。`templateOutline` 为 Word 模板文件下载地址，服务端会下载 `.docx` 模板并提取其中的文字内容作为报告大纲要求。

### params参数结构

| 字段 | 类型 | 说明 | 示例值 |
|------|------|------|--------|
| filePathList | Array | 文件下载地址列表（支持多文件） | `["http://.../file1.sql", "http://.../file2.sql"]` |
| reportId | Long | 报告唯一标识（业务主键） | `132` |
| templateDesc | String | 模板说明信息 | `"1231231"` |
| templateOutline | String | Word模板文件下载地址（服务端下载后提取文字内容作为模板大纲） | `"http://.../template.docx"` |
| requirement | String | 业务需求描述 | `"要求"` |

### 请求示例

```json
{
  "businessType": "report",
  "params": [
    {
      "filePathList": [
        "http://localhost:8080/file/download/ad92572918564809bdeb61af1a06486a.sql",
        "http://localhost:8080/file/download/d472f05fa3344738953d027ad598ff67.sql"
      ],
      "reportId": 132,
      "templateDesc": "1231231",
      "templateOutline": "http://localhost:8080/file/download/report-template.docx",
      "requirement": "业务需求描述，报告xxxx要求"
    }
  ]
}
```

## 3. 检测大模型任务接口

**接口路径：** `/llm/check-task`  
**请求方法：** `POST`  
**功能说明：** 检测大模型任务状态，对已解析成功但未回调的任务触发回调

### 文件类型请求参数

| 参数 | 类型 | 说明 | 必填 |
|------|------|------|------|
| businessType | String | 固定值："file" | 是 |
| params | Array | 仅含fileName参数的对象数组 | 是 |

### params元素结构（文件类型）

| 字段 | 类型 | 说明 |
|------|------|------|
| fileName | String | 文件对象名（业务主键） |

### 文件类型请求示例

```json
{
  "businessType": "file",
  "params": [
    {
      "fileName": "bded228dc94440519d87f97cfb6b520b.pdf"
    }
  ]
}
```

> 项目兼容扩展说明：`/llm/check-task` 支持一次传入多个 `fileName`；单项查询保持原返回结构，批量查询时 `data` 返回数组。

### 报告类型请求参数

| 参数 | 类型 | 说明 | 必填 |
|------|------|------|------|
| businessType | String | 固定值："report" | 是 |
| params | Array | 仅含reportId参数的对象数组 | 是 |

### params元素结构（报告类型）

| 字段 | 类型 | 说明 |
|------|------|------|
| reportId | Long | 报告唯一标识（业务主键） |

### 报告类型请求示例

```json
{
  "businessType": "report",
  "params": [
    {
      "reportId": 132
    }
  ]
}
```

## 4. 大模型任务进度推送接口

**接口路径：** `/llm/progress`  
**通信方式：** `WebSocket`  
**触发时机：** 调用文件解析/报告生成接口后自动建立连接推送进度

### 消息请求参数（客户端→服务端）

> 项目兼容扩展说明：除首条消息直接发送订阅 JSON 外，也支持显式动作消息：
>
> - `{"action":"subscribe","businessType":"file","params":[...]}`
> - `{"action":"query","businessType":"file","params":[...]}`
> - `{"action":"unsubscribe","businessType":"file","params":[...]}`
>
> 一个 WebSocket 连接可同时管理多个任务订阅。

#### 文件类型请求结构

```json
{
  "businessType": "file",
  "params": [
    {
      "fileName": "bded228dc94440519d87f97cfb6b520b.pdf"
    }
  ]
}
```

#### 报告类型请求结构

```json
{
  "businessType": "report",
  "params": [
    {
      "reportId": 132
    }
  ]
}
```

### 消息响应参数（服务端→客户端）

#### 文件类型响应结构

| 字段 | 类型 | 说明 |
|------|------|------|
| businessType | String | 固定值："file" |
| data.fileName | String | 文件对象名（业务主键） |
| data.progress | Number | 解析进度（0.0～1.0） |

```json
{
  "businessType": "file",
  "data": {
    "fileName": "bded228dc94440519d87f97cfb6b520b.pdf",
    "progress": 0.69
  }
}
```

#### 报告类型响应结构

| 字段 | 类型 | 说明 |
|------|------|------|
| businessType | String | 固定值："report" |
| data.reportId | Long | 报告唯一标识 |
| data.progress | Number | 生成进度（0.0～1.0） |

```json
{
  "businessType": "report",
  "data": {
    "reportId": 132,
    "progress": 0.89
  }
}
```

## 5. 大模型回调接口

**接口路径：** `/llm/callback`  
**请求方法：** `POST`  
**功能说明：** 大模型处理完成后回调业务系统，返回结构化结果

### 文件解析回调参数

| 参数 | 类型 | 说明 |
|------|------|------|
| businessType | String | 固定值："file" |
| data.fileName | String | 文件对象名（业务主键） |
| data.country | String | 国家（解析结果） |
| data.channel | String | 资料来源机构（解析结果）；只能返回请求 `params[].channel` 候选中的 `value`，请求未提供有效候选时返回空字符串 |
| data.maturity | String | 成熟度（解析结果） |
| data.security | String | 密级（解析结果）；从请求 `params[].security` 候选 value 中选取，文件开头未见相关说明时默认为“公开” |
| data.format | String | 原生格式（解析结果） |
| data.status | String | 解析状态（0未解析 1解析中 2已解析 3解析失败）（解析结果） |
| data.architectureId | Long | 领域体系ID（解析结果） |
| data.fileDataItem | Object | 文件解析详细数据（见下表） |
| msg | String | 回调消息（如"解析成功"） |

### fileDataItem字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| fileName | String | 文件名(对象名) |
| dataTime | String | 资料年代（ISO8601）yyyy-MM-dd |
| keyword | String | 关键词 |
| summary | String | 摘要 |
| score | Integer | 资料来源权威性评分，必填且仅返回 `95`、`85`、`75`、`65`、`55` |
| fileNo | String | 文件编号 |
| source | String | 资料来源 |
| originalLink | String | 原文链接 |
| language | String | 语种 |
| dataFormat | String | 资料格式 |
| associatedEquipment | String | 所属装备 |
| relatedTechnology | String | 所属技术 |
