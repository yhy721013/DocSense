## 1. 大模型文件解析接口

**接口路径：** `/llm/analysis`  
**请求方法：** `POST`  
**功能说明：** 提交文件进行大模型解析，支持多维度业务参数配置

### 请求参数说明

| 参数 | 类型 | 说明 | 必填 |
|------|------|------|------|
| businessType | String | 业务类型标识，固定值："file" | 是 |
| params | Array | 请求参数列表（项目兼容单项与多项；多项时按顺序串行处理） | 是 |

> 项目兼容扩展说明：`/llm/analysis` 支持 `mhtml`/`mht` 文件；服务端下载后会先提取正文文本，再复用现有大模型解析流程。

### params参数结构

| 字段 | 类型 | 说明 | 示例值 |
|------|------|------|--------|
| architectureList | Array | 领域体系列表（范围） | 见下方示例 |
| architectureStandardList | Array | 数据标准额外解析范围；最终分类命中该范围或其子孙节点时，回调 `fileDataItem` 额外返回数据标准字段 | `[{"id":1768464916588441,"name":"国家军用标准"}]` |
| channel | Array | 资料来源机构候选列表（字典编码）；服务端仅使用请求提供的候选，不注入默认候选。未传、传空数组或没有有效候选对象时，模型和回调均输出空字符串 | `[{"value":"装发","key":"02"}]` |
| country | Array | 国家列表（范围）（字典编码） | `[{"value":"美国","key":"02"}]` |
| fileName | String | 文件对象名（业务主键） | `"bded228dc94440519d87f97cfb6b520b.pdf"` |
| originalFileName | String | 业务原始文件名，服务端保留请求原值；除辅助大模型理解文件主题外，还作为后续知识谱系回调来源展示名 | `"GJB 9001C-2017 质量管理体系要求.pdf"` |
| filePath | String | 文件下载地址（格式 application/octet-stream） | `"http://localhost:8080/file-download/..."` |
| format | Array | 原生格式列表（范围）（字典编码） | `[{"value":"文档类","key":"03"}]` |
| maturity | Array | 成熟度列表（范围）（字典编码） | `[{"value":"阶段成果","key":"02"}]` |
| security | Array | 密级列表（范围）（字典编码）；解析时根据文档开头内容判断密级，未见相关说明则默认为“公开” | `[{"value":"公开","key":"02"}]` |

### architectureList元素结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 领域体系唯一标识 |
| name | String | 领域名称 |
| parentId | Long | 父节点 id；根节点可为空或不传 |
| path | String | 从根节点到当前节点的 id 链 |
| pathName | String | 从根节点到当前节点的名称链 |
| remark | String | 节点名词概述，用于辅助大模型理解该节点含义 |

### architectureStandardList元素结构

`architectureStandardList` 使用与 `architectureList` 相同的节点结构。该列表表示需要额外解析数据标准字段的分类范围，可以只传部分节点，也可以传包含“数据标准”树根节点的完整节点列表。

领域分类规则：

- 当 `architectureList` 只有一个节点时，解析结果直接返回该节点 `id`，不再让大模型判断文件所属领域；其他信息提取仍正常执行。
- 当 `architectureList` 包含多个节点时，优先分类到最具体的叶子节点。
- 如果叶子节点证据不足，选择最深的可靠父节点。
- 服务端只要求最终 `architectureId` 是请求 `architectureList` 中的整数候选；普通领域的父节点属于合法结果，不会因不是叶子节点而拒绝成功回调或永久入库；“数据标准”分支父节点适用后续 GJB 叶子节点特殊规则。
- 如果多个兄弟节点都可能，选择它们的最近公共父节点。
- 当最终分类名称严格符合 `*-基础数据`、`*-战技指标`、`*-运用数据` 或 `*-效能数据` 时，回调中的 `data.architectureId` 仍返回该具体子分类 ID；服务端内部知识库统一按对应的武器装备父节点 ID 存储。该内部归并不会改变本接口的回调结构和分类结果。
- 当文档内容明确为 GJB、国军标、国家军用标准相关资料，且候选中存在 `数据标准` 节点时，`architectureId` 返回该分支下的子节点（叶子节点）id，禁止返回 `数据标准` 父节点 id；多个叶子均可选或无法区分时，按请求 `architectureList` 的原始顺序返回第一个叶子节点 id。
- 当最终 `architectureId` 命中 `architectureStandardList` 范围或其子孙节点时，回调 `fileDataItem` 额外返回 `militaryName`、`num`、`startTime`、`implTime`、`approvalDept`；未命中时不返回这 5 个字段。
- 多候选场景下，首次 `architectureId` 不合规时会先按 GJB/国军标正文线索匹配数据标准分支下按顺序可命中的叶子节点，再执行一次分类修复；模型直接返回数据标准父节点时，也会直接按该顺序兜底到叶子节点。最终仍未返回请求中的整数候选时，任务解析失败，不发送成功回调，也不写入永久知识库。

`score` 评分规则：

- 闭源渠道或权威机构公开发布，如军政官方机构网站或正式出版物，评分 `95`。
- 专业科研单位，如兰德、简氏等知名智库及装备研制单位等，评分 `85`。
- 专业信息网站，如海上舰艇交通网、美舰艇历史与部署网、海军学院新闻网、防务新闻网等，评分 `75`。
- 普通信息网站，如综合性新闻网、百度百科等，评分 `65`。
- 未明确数据来源的资料，评分 `55`。

### 受理成功响应（HTTP 202）

请求通过校验并成功受理后，响应体为空。调用方使用请求中原有的 `fileName` 通过进度 WebSocket、`/llm/check-task` 的恢复触发或最终回调跟踪任务，不从受理响应获取内部任务 ID。

```http
HTTP/1.1 202 Accepted
Content-Length: 0
```

HTTP 400、409 等错误响应仍按既有 JSON 错误体返回。

## 2. 大模型报告生成接口

**接口路径：** `/llm/generate-report`  
**请求方法：** `POST`  
**功能说明：** 基于多文件内容生成结构化分析报告

### 请求参数说明

| 参数 | 类型 | 说明 | 必填 |
|------|------|------|------|
| businessType | String | 业务类型标识，固定值："report" | 是 |
| params | Array | 请求参数列表（仅使用第一个元素） | 是 |

> 项目兼容扩展说明：`/llm/generate-report` 的 `filePathList` 可包含 `mhtml`/`mht` 文件；服务端下载后会先提取正文文本，再参与报告生成。`templateOutline` 为 Word 模板文件下载地址，服务端会下载 `.docx` 模板并提取其中的文字内容作为报告大纲要求。

### params参数结构

| 字段 | 类型 | 说明 | 示例值 |
|------|------|------|--------|
| filePathList | Array | 文件下载地址列表（支持多文件） | `["http://.../file1.sql", "http://.../file2.sql"]` |
| reportId | Integer / String | 报告唯一标识（业务主键）；可传 JSON 整数或十进制整数字符串 | `132` 或 `"132"` |
| templateDesc | String | 模板说明信息 | `"1231231"` |
| templateOutline | String | Word模板文件下载地址（服务端下载后提取文字内容作为模板大纲） | `"http://.../template.docx"` |
| requirement | String | 业务需求描述 | `"要求"` |

`reportId` 入站值不设置 32 位、64 位或正负号等业务数值范围限制。字符串形式允许首尾
空白、可选正负号和前导零，但去除空白后必须完全由可选的 `+`/`-` 与十进制数字组成；
布尔值、浮点数和含小数点/指数/其他字符的字符串均视为参数错误。服务端按整数值统一
业务主键，因此 `132`、`"132"`、`"+132"` 和 `"00132"` 表示同一报告任务。调用方
如无法保证其 JSON number 实现对大整数无损，应优先使用整数字符串传入。

> 实施状态：上述 `reportId` 入站兼容及规范化已于 2026-07-16 在报告生成、报告类型
> check-task 和报告类型 Progress 的当前代码路径中统一实现；未改变任何字段集合或
> 服务端输出类型。

### 请求示例

```json
{
  "businessType": "report",
  "params": [
    {
      "filePathList": [
        "http://localhost:8080/file/download/ad92572918564809bdeb61af1a06486a.sql",
        "http://localhost:8080/file/download/d472f05fa3344738953d027ad598ff67.sql"
      ],
      "reportId": 132,
      "templateDesc": "1231231",
      "templateOutline": "http://localhost:8080/file/download/report-template.docx",
      "requirement": "业务需求描述，报告xxxx要求"
    }
  ]
}
```

### 受理与重复提交

- 当同一 `reportId` 不存在生成中的任务时，服务端返回 HTTP `202`、空响应体并受理报告生成任务。
- 报告公开状态 `status="0"` 表示生成中。若同一 `reportId` 已存在该活动状态，重复提交返回 HTTP `409`，且不创建新任务、不启动后台执行、不覆盖原任务投影。
- 原任务进入 `status="1"`（已生效）或 `status="2"`（生成失败）后，允许再次提交同一 `reportId`。
- HTTP 400、409 等错误响应仍按既有 JSON 错误体返回。

#### 首次受理成功（HTTP 202）

```http
HTTP/1.1 202 Accepted
Content-Length: 0
```

#### 活动任务重复提交（HTTP 409）

```json
{
  "error": "任务正在处理中"
}
```

> 实施状态：202 空响应体与活动任务 409 均已于 2026-07-15 明确确认；当前代码尚未实现，计划在 `docs/重构记录/260715-其余业务分层统一改造实施计划.md` 波次 1C 一并落地。实现完成前，联调不得把“当前 JSON 受理响应”或“仍可能重复受理”误认为目标契约。

## 3. 检测大模型任务接口

**接口路径：** `/llm/check-task`  
**请求方法：** `POST`  
**功能说明：** 检查任务是否需要回调恢复；对满足条件的终态任务触发一次回调补发

`params` 必须是非空 JSON 数组，且其中每个元素都必须是 JSON 对象。只要出现任意非对象元素，服务端即把**整次请求**判定为参数错误，返回 HTTP 400 与既有单字段 JSON 错误体；不得过滤无效元素后继续处理其余对象。

### 文件类型请求参数

| 参数 | 类型 | 说明 | 必填 |
|------|------|------|------|
| businessType | String | 固定值："file" | 是 |
| params | Array | 仅含fileName参数的对象数组 | 是 |

### params元素结构（文件类型）

| 字段 | 类型 | 说明 |
|------|------|------|
| fileName | String | 文件对象名（业务主键） |

### 文件类型请求示例

```json
{
  "businessType": "file",
  "params": [
    {
      "fileName": "bded228dc94440519d87f97cfb6b520b.pdf"
    }
  ]
}
```

> 项目兼容扩展说明：`/llm/check-task` 支持一次传入多个 `fileName`；服务端按请求顺序逐项检查并尝试必要的回调恢复。

### 报告类型请求参数

| 参数 | 类型 | 说明 | 必填 |
|------|------|------|------|
| businessType | String | 固定值："report" | 是 |
| params | Array | 仅含reportId参数的对象数组 | 是 |

### params元素结构（报告类型）

| 字段 | 类型 | 说明 |
|------|------|------|
| reportId | Integer / String | 报告唯一标识（业务主键）；可传 JSON 整数或十进制整数字符串，规范化规则与报告生成接口相同 |

### 报告类型请求示例

```json
{
  "businessType": "report",
  "params": [
    {
      "reportId": "132"
    }
  ]
}
```

### 成功响应与副作用（HTTP 200）

请求参数有效且检查流程完成后，响应体为空。该接口不是纯查询：服务端可能在返回前同步尝试一次回调补发，并更新内部回调状态。调用方不得依赖响应体判断任务或回调结果，最终业务结果仍以回调为准。

```http
HTTP/1.1 200 OK
Content-Length: 0
```

- 单项任务不存在时，继续返回现有 HTTP 404 与 JSON 错误体。
- 参数错误继续返回现有 HTTP 400 与 JSON 错误体。
- 批量请求中的缺失任务不会使整批失败；其余存在任务仍执行检查，完成后返回 HTTP 200 空响应体。

参数错误体继续使用现有结构，不增加字段：

```json
{
  "error": "参数错误原因"
}
```

> 实施状态：200 空响应体与严格 `params` 元素校验均已于 2026-07-15 明确确认；阶段 1B-1 已完成可靠恢复命令的内部边界，但当前代码仍返回任务状态、进度和回调恢复结果 JSON，并会过滤混合数组中的非对象元素。生产运行路径计划在总计划阶段 6、MySQL/Outbox、RabbitMQ 和 callback Worker 可靠链路就绪后一次性切换。内部仍必须持久化并审计回调补发结果，只是不再通过本接口响应体公开。

## 4. 大模型任务进度推送接口

**接口路径：** `/llm/progress`  
**通信方式：** `WebSocket`  
**触发时机：** 调用文件解析/报告生成接口后，由客户端建立连接并发送订阅消息

### 消息请求参数（客户端→服务端）

客户端直接发送不含 `action` 的订阅 JSON。`params` 可包含一个或多个任务；服务端立即发送各任务当前快照，并在连接存续期间继续推送后续进度。关闭连接即取消该连接的全部订阅。

报告类型订阅的 `reportId` 采用与报告生成、check-task 相同的入站规则：允许 JSON
整数或十进制整数字符串，不设置业务数值范围；服务端按整数值规范化订阅键。参数格式
错误时只拒绝当前 WebSocket 消息、返回 error 并保持连接。服务端到客户端的
`data.reportId` 仍保持既有 JSON number 类型，不改变响应字段或类型。

`params` 必须是非空 JSON 数组，且其中每个元素都必须是 JSON 对象。只要出现任意非对象元素，服务端即拒绝**整条 WebSocket 消息**，不处理其中任何订阅项，返回错误消息并保持连接；客户端随后仍可发送合法订阅消息。

`action=subscribe/query/unsubscribe`、ack 控制消息属于项目曾经自行增加的内部扩展，没有甲方或生产前端需求依据，不属于目标公开契约，已在重构阶段 1B-2 下线。收到任何带 `action` 的消息时，服务端拒绝整条消息、返回错误消息、不发送 ack，并保持连接。调用方不得再依赖旧控制消息。

#### 文件类型请求结构

```json
{
  "businessType": "file",
  "params": [
    {
      "fileName": "bded228dc94440519d87f97cfb6b520b.pdf"
    }
  ]
}
```

#### 报告类型请求结构

```json
{
  "businessType": "report",
  "params": [
    {
      "reportId": "00132"
    }
  ]
}
```

#### 参数或控制消息错误响应

错误消息沿用既有字段结构，不增加替代控制字段；`message` 的具体文字用于说明本次错误原因，不作为稳定枚举值：

| 字段 | 类型 | 说明 |
|------|------|------|
| type | String | 固定值：`"error"` |
| message | String | 参数或控制消息错误原因 |

```json
{
  "type": "error",
  "message": "参数或控制消息错误原因"
}
```

上述校验失败只拒绝当前客户端消息，WebSocket 连接保持打开，不返回 ack。

> 实施状态：严格 `params` 元素校验，以及显式 `action` 返回错误消息、保持连接且不发送 ack 的目标行为已于 2026-07-15 明确确认，并已于 2026-07-16 在重构阶段 1B-2 的当前代码运行路径中实现。

### 消息响应参数（服务端→客户端）

#### 文件类型响应结构

| 字段 | 类型 | 说明 |
|------|------|------|
| businessType | String | 固定值："file" |
| data.fileName | String | 文件对象名（业务主键） |
| data.progress | Number | 解析进度（0.0～1.0） |

```json
{
  "businessType": "file",
  "data": {
    "fileName": "bded228dc94440519d87f97cfb6b520b.pdf",
    "progress": 0.69
  }
}
```

#### 报告类型响应结构

| 字段 | 类型 | 说明 |
|------|------|------|
| businessType | String | 固定值："report" |
| data.reportId | Long | 报告唯一标识 |
| data.progress | Number | 生成进度（0.0～1.0） |

```json
{
  "businessType": "report",
  "data": {
    "reportId": 132,
    "progress": 0.89
  }
}
```

## 5. 大模型回调接口

**接口路径：** `/llm/callback`  
**请求方法：** `POST`  
**功能说明：** 大模型处理完成后回调业务系统，返回结构化结果

### 文件解析回调参数

| 参数 | 类型 | 说明 |
|------|------|------|
| businessType | String | 固定值："file" |
| data.fileName | String | 文件对象名（业务主键） |
| data.country | String | 国家（解析结果） |
| data.channel | String | 资料来源机构（解析结果）；只能返回请求 `params[].channel` 候选中的 `value`，请求未提供有效候选时返回空字符串 |
| data.maturity | String | 成熟度（解析结果） |
| data.security | String | 密级（解析结果）；从请求 `params[].security` 候选 value 中选取，文件开头未见相关说明时默认为“公开” |
| data.format | String | 原生格式（解析结果） |
| data.status | String | 解析状态（0未解析 1解析中 2已解析 3解析失败）（解析结果） |
| data.architectureId | Long | 领域体系ID（解析结果） |
| data.fileDataItem | Object | 文件解析详细数据（见下表） |
| msg | String | 回调消息（如"解析成功"） |

### fileDataItem字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| fileName | String | 文件名(对象名) |
| dataTime | String | 资料年代（ISO8601）yyyy-MM-dd |
| keyword | String | 关键词 |
| summary | String | 摘要 |
| score | Integer | 资料来源权威性评分，必填且仅返回 `95`、`85`、`75`、`65`、`55` |
| fileNo | String | 文件编号 |
| source | String | 资料来源 |
| originalLink | String | 原文链接 |
| language | String | 语种 |
| dataFormat | String | 资料格式 |
| associatedEquipment | String | 所属装备 |
| relatedTechnology | String | 所属技术 |
| equipmentModel | String | 装备型号 |
| documentOverview | String | 文件概述 |
| originalText | String | 文件原文 |
| documentTranslationOne | String | 文件翻译单语 |
| documentTranslationTwo | String | 文件翻译双语 |
| militaryName | String | 国军标名称；仅当最终分类命中 `architectureStandardList` 范围时返回 |
| num | String | 编号；仅当最终分类命中 `architectureStandardList` 范围时返回 |
| startTime | String | 发布时间，格式 `yyyy-MM-dd`；仅当最终分类命中 `architectureStandardList` 范围时返回 |
| implTime | String | 实施时间，格式 `yyyy-MM-dd`；仅当最终分类命中 `architectureStandardList` 范围时返回 |
| approvalDept | String | 批准部门；仅当最终分类命中 `architectureStandardList` 范围时返回 |

### 报告生成回调参数

| 参数 | 类型 | 说明 |
|------|------|------|
| businessType | String | 固定值："report" |
| data.reportId | Long | 报告唯一标识 |
| data.details | String | 报告内容（HTML富文本格式） |
| data.status | String | 报告状态（0生成中 1已生效 2生成失败） |
| msg | String | 回调消息（如"生成成功"） |

### 报告回调请求示例

#### 生成成功

```json
{
  "businessType": "report",
  "data": {
    "reportId": 132,
    "status": "1",
    "details": "<div class=\"report-title\">\n  <span style=\"color: #ff6b6b;\">📄</span>\n  <span style=\"margin-left: 8px; font-size: 20px;\">报告内容</span>\n</div>"
  },
  "msg": "生成成功"
}
```

#### 生成失败（更新状态）

```json
{
  "businessType": "report",
  "data": {
    "reportId": 132,
    "status": "2",
    "details": ""
  },
  "msg": "生成失败"
}
```
