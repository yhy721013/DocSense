## 1. 当前依赖方向

```text
HTTP / WebSocket / SSE
  -> app/blueprints                         Flask 协议入口，只做协议接线
  -> app/adapters/web/flask                 框架入站解析
  -> app/modules/*/application              用例编排，只依赖 Port
  -> app/modules/*/ports                    业务所需能力合同
  <- app/modules/*/adapters                 SQLite、本地文件和供应商适配
  <- app/integrations/anythingllm           供应商协议与 Transport

Application result
  -> app/presenters                         公开响应、Callback、SSE/WS 投影
  -> app/blueprints                         Flask Response / WebSocket 发送

app/container.ApplicationServices
  -> 装配上述实例及生命周期
  -> 不导入 Flask，不读取 request/current_app，不启动临时生产依赖
```

固定规则：

1. Blueprint 不直接创建 SQLite 连接、AnythingLLM Client、后台线程或业务文件；
2. Application 不依赖 Flask、具体数据库类或供应商 SDK；
3. Domain 不依赖 Application、Adapter、Web 或供应商实现；
4. `app/container.py` 是正式组合根，`app/blueprints/dependencies.py` 是 Flask 容器访问边界；
5. Debug 遵循 `Blueprint -> Query -> Port <- Adapter`，只允许本地只读查询；
6. Callback、Progress、SSE、WebSocket 和公开错误映射仍受接口文档与黄金资产约束。
