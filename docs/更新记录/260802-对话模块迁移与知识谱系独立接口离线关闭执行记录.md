## 2. 公开接口影响

本次落地的是已于 2026-08-01 批准并冻结的合同，没有在实施中继续增删参数：

- 新增 `POST /llm/weaponry-chat`、`POST /llm/weaponry-chat/title`、
  `GET /llm/weaponry-chat/history`、`POST /llm/weaponry-chat/abort` 和
  `POST /llm/weaponry-chat/delete`；
- 固定 `businessType="weaponryChat"`，以可信 DocSense `userId + architectureId` 作为公开
  复合身份；两个 ID 均受 JavaScript 安全正整数边界约束，History Query 允许前导零并严格拒绝
  未知字段和重复参数；
- `/llm/chat*` 只保留文件对话 `chatId + fileNames`，不兼容旧
  `chatId + architectureId` 知识谱系模式；
- Weaponry Chat 成功 SSE 依次发送 `chatInfo`、文本、恰好一次 `sourceChunks` 和 `done`，并
  使用 `Content-Type: text/event-stream`、`Cache-Control: no-cache`、
  `X-Accel-Buffering: no`；History 保持裸消息数组，assistant `chunks` 与 SSE 来源内容和顺序
  完全一致；
- Chunk 正文只接受字符串并无损保存；来源必须通过结构化键唯一匹配，缺失非空
  `originalFileName` 时整个类别范围严格失败，不回退到 `fileName`。

## 3. 模块与数据边界

- `app/modules/chat/` 现拥有 Domain、Application、Ports、SQLite Adapter、AnythingLLM Chat
  Adapter 和唯一组合根；正式路由只读取 `ApplicationServices.chat_services`，不会重复构造
  数据库、供应商 Client 或后台线程；
- 文件身份和 Weaponry 复合身份共用内部 `conversationId`、运行状态机、持久化和资源清理，
  但由独立 Web Parser、策略与 Presenter 隔离公开合同；
- File `chatId` 删除后保留永久墓碑，不能被通用解析误建为新会话；Weaponry 身份只在远端清理
  全部成功后释放，再次进入会建立新 Conversation 和新直接文件快照；
- 删除成功物理清除消息与 `message_source_chunks` 正文，只保留不含消息、Chunk、文件名、来源或
  用户 ID 的最小审计事实；
- 首次类别快照只包含当时直接文件，后续不刷新。受理、Scope、pending user、回复正文、全部
  Chunk、成功 Event 与 Run 终态分别在规定的 SQLite 事务边界内原子提交。

## 4. AnythingLLM v1.15.0 流语义

共享 Threads 客户端不再在第一个 `close=true` 时提前返回：常规回答继续读取唯一
`finalizeResponseStream.sources`；Query 明确无上下文时允许
`textResponse(close=true, sources=[])` 收敛。缺失、重复、顺序冲突或来源映射失败均 fail closed，
不保存不完整 assistant/Chunk。对应供应商流 Fixture 已冻结在
`tests/contracts/anythingllm_v1_15_stream.jsonl`。

## 5. 安全、容量与未来部署边界

- 应用日志门禁验证不记录 API secret、`userId`、消息、Chunk、文件名、原文件名、来源 URL 或
  Workspace/Thread 引用；部署时仍须关闭或脱敏 History 原始 Query String，并禁止请求体、SSE
  和响应体进入 Web Server、Gateway、APM 或异常快照；
- 当前不为 Chunk 数量、Chunk 正文长度或 History 响应大小增加独立业务上限，也不分页、截断或
  改写；受控样本验证了 64 个 Chunk、262,656 字符来源正文及 1,581,664 bytes History Body，
  该样本不是容量承诺；
- 当前 SQLite、内联调度、进程内通知和本地清理只证明单实例语义。共享数据库、可靠队列、
  多实例通知、fencing 与生产高并发能力仍未实现。
