# 知识谱系类别文件对话阶段 1 选择器与纯领域执行记录

## 1. 阶段范围

本阶段实现尚未接入公开路由的 architecture/fileNames Web 选择器，以及纯 Chat Domain 的
Candidate、Session Binding 和 Scope 状态机。没有修改 SQLite、Resolver、Executor、History
或 `/llm/chat` 当前执行链。

## 2. 实现内容

- 新增框架无关 `parse_chat_scope_selector`：
  - 按字段存在性拒绝 `architectureId + fileNames=[]`；
  - 复用既有 architecture ID Web 规范化；
  - 向 Chat Domain 只传规范化 `int`；
  - 两字段均缺失时保持 `fileNames必须为数组`；
  - fileNames 继续按首次出现稳定去重。
- Candidate 内部 Schema 升级为 v2：
  - 新增 `ChatArchitectureCandidates`；
  - 严格表达 `resolved/not_found/invalid`；
  - 写入 v2，迁移窗口内继续严格读取 v1；
  - architecture 与 explicit/default 文件候选不可混合。
- 新增不可变 `ChatScopeSelector`、`ChatSessionScopeBinding` 和绑定纯决策：
  - 会话模式不可切换；
  - architecture ID 不可切换；
  - 冲突使用类型化 Domain Error。
- Scope 状态机新增 `architecture_initial`、`architecture_reuse`：
  - 新会话才消费候选错误；
  - 既有同 ID 会话忽略当前目录 outcome，复用已冻结成员；
  - architecture Revision 携带 `source_architecture_id`。
- 新增 AST 边界门禁，Chat Domain 不导入 Flask、SQLite、Web Adapter、Weaponry 或供应商实现。
