# 文件对话请求与活动范围分离阶段 0 执行记录

## 1. 范围

本阶段只冻结 `/llm/chat` 后续改造的状态机与公开契约不变量，不修改生产代码、SQLite
Schema 或权威接口文档。

已冻结：

- 首次空数组创建一次 `automatic_initial` 全量快照；
- 任意非空数组整体替换 Active Scope；
- 后续空数组复用 Scope Head；
- 后续新增知识库文件不自动吸收；
- history 用户 `files` 只展示该轮前端显式文件；
- 不新增请求字段、响应字段或 SSE 事件。

## 2. 新增资产

- `tests/contracts/chat_scope_state_machine.json`
- `tests/test_chat_scope_contract_assets.py`

黄金资产包含 6 组状态：

1. 新会话空数组且目录非空；
2. 新会话空数组且目录为空；
3. 新会话首轮显式文件；
4. 既有会话空数组复用首次自动范围；
5. 既有会话非空数组替换范围；
6. 显式范围之后空数组保持最后显式范围。
