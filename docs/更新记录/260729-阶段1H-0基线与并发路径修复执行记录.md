## 2. 1H-0R 并发路径问题

### 2.1 发现

新 50 任务门禁首次运行时，`LocalAnalysisTaskWorkspaceAdapter` 在全新根目录并发创建任务目录：

```text
root:      C:\...\analysis
task_root: \\?\C:\...\analysis\stage1h-baseline-00
```

两个字符串指向相同 Windows 位置，但 `Path.relative_to` 会把它们视为不同根，从而抛出
“任务目录越出受控根目录”。上层只保证 `RUNTIME_DIR` 已创建，不保证 `RUNTIME_DIR/tasks` 在
第一个 Analysis 任务前存在，因此这不是测试独有条件。

### 2.2 负责人确认

1H-0 原计划不修改生产代码。发现该问题后停止改造并请求确认；负责人同意增加窄范围 1H-0R，
修复后再关闭阶段 0。

### 2.3 修复

修改 `app/modules/analysis/adapters/legacy_files.py`：

1. 构造根目录和每次计算任务目录时统一调用 `_canonical_resolved`；
2. 先由 `Path.resolve` 解析符号链接和 `..`；
3. 仅移除等价的 `\\?\` 或 `\\?\UNC\` Win32 前缀；
4. 继续使用 `relative_to` 验证真实包含关系；
5. 不改变 TaskId 校验、目录命名、创建时点、日志和资源清理语义。

该方法与 `LocalReportArtifactAdapter` 已验证的 Windows 规范化方式保持一致。
