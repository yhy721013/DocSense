## 3. 最终结构事实

1. `app/container.py` 是框架无关生产组合根；Flask 只通过依赖访问 Adapter 获取已装配服务。
2. 正式 Blueprint 只承担请求解析、Application 调用和 Presenter 输出，不直接构造数据库、供应商客户端、执行线程或恢复器。
3. `/debug/*` 是只读 Query 边界，但仍需在生产网络/反向代理层限制访问；应用内只读不等于可公开暴露。
4. 每个静态 SQLite 表都有唯一模块 owner；跨模块只通过 Port/Facade 访问，不允许绕过所有权直接写表。
5. 遗留代码必须先完成生产引用、测试价值、配置/文档引用三类盘点，再决定迁移、保留或物理删除。
6. 历史兼容入口只在明确调用方仍存在时保留，不能成为第二生产执行链。
