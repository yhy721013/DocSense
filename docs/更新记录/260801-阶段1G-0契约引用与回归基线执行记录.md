## 2. 冻结的路由事实

离线应用工厂在注入测试服务后得到 15 条项目路由：4 条 `/debug/*` 路由与 11 条 `/llm/*` 路由。
黄金资产按“HTTP 方法 + 精确路径”校验整个集合，避免后续只验证局部端点而遗漏路由漂移。

Debug JSON 继续冻结以下边界：

- Callback：`ok`、`records`、`selected`、`error`、`maxRecords` 及既有错误文案；
- Chat：`ok`、`sessions`、`availableFiles`、`error`，其中 `fileNames` 表示 Active Scope，
  `bindingCount` 独立表示累计绑定数量；
- 页面：保留 Callback 与 Chat 页面所依赖的关键 DOM 标识和查询字段。
