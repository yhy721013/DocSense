```powershell
venv\Scripts\python.exe -B scripts\inspect_analysis_cutover.py --database <已确认的SQLite文件> --limit 50
```

`running` execution 任一存在时，必须停止发布并人工处置。不得在线双跑新旧链路、盲目补发 Callback、
重放 RAG/知识库副作用，或将 `running` 强行改回 `accepted`。
