## 1. 结论

1F-4 已建立文件分析新链路所需的批量原子受理基础：每个受理批次具有一个内部 `batch_id`，每项具有
请求内连续 `batch_sequence`，整批在同一个 SQLite `BEGIN IMMEDIATE` 事务中取得连续的全局
`dispatch_sequence`。受理事实写入追加式 `llm_task_executions`，而 `llm_tasks` 继续仅作为既有
file Progress/check-task 的最新公开投影。

受理成功后，Application 只尝试一次 Dispatcher 唤醒；唤醒异常会记录错误，但绝不撤销已经提交的
accepted execution。后续 Dispatcher 可通过持久扫描发现积压，因此 Event 只是有界唤醒信号，不是
内存队列或可靠队列本体。

本阶段未修改 `docs/接口文档/`、`app/blueprints/llm.py`、公开路由、请求/响应参数、状态码、Header、
Progress 或 Callback。没有启动 `run.py`，没有连接真实模型、AnythingLLM、OCR、Callback 或其他后台服务。

### 2.1 原子性与旧公开投影

- 批次内所有 execution 在同一个写事务中插入，任一 execution 或 `llm_tasks` 投影写入/读回失败时，
  此前已经插入的 execution 一并回滚。
- 首项仍写入既有公开处理中状态 `1`，后续项仍写入等待状态 `0`；这些只存在于旧公开投影，不向新
  HTTP、Progress 或 Callback 额外暴露 TaskId、batchId 或 sequence。
- 仅在旧投影处于已完成状态、回调处于 `success`/`failed`/`skipped`，且没有有效回调租约时才允许覆盖。
  覆盖时显式清理已过期的旧 `callback_claim_id` 和 deadline，避免新 execution 继承旧发送权。
- `pending`、有效 sending 租约、Guard `sending` 或 `outcome_unknown` 均拒绝新批次；不能判定外部副作用时
  保持冻结，不盲目重放或覆盖。

### 2.2 顺序与恢复发现

- SQLite 写事务为不同请求串行分配全局 `dispatch_sequence`；同一批次预留连续区间，两个批次不会交叉。
- `batch_sequence` 表示请求内顺序，`dispatch_sequence` 表示跨批全局扫描顺序；Adapter、Service 和
  Application 均核对回显身份，不依赖进程内可变列表保存积压。
- 新扫描入口仅返回同时具有 `batch_id` 和 `batch_sequence` 的 accepted file execution，避免未来
  Dispatcher 误领旧兼容 file 链路。
- 唤醒失败后的离线验证仍能从该持久扫描入口取得本批 TaskId；这只是后续恢复机制的基础，真实 Dispatcher
  尚未接线。

## 4. 公开接口与运行边界

- `docs/接口文档/` 保持零修改，不需要接口确认；本次没有增删任何前后端接口参数。
- 当前 `/llm/analysis` 与 file 类型 `/llm/check-task` 仍使用遗留路由/执行链；新批量 Command、
  `SubmitAnalysisBatch`、新 Adapter 和扫描入口尚未装配进 Container、Worker 或 Dispatcher。
- 1F-4 没有实现资源记录/恢复、真实 Callback 投递、生命周期管理或路由切换；这些仍由 1F-6、1F-5A/
  1F-5B 和后续验收承担。
- 当前验证只覆盖 SQLite `single_instance` 过渡模式的离线原子性。它不等同于可靠任务队列、多实例部署、
  分布式协调、高并发模型执行吞吐或生产就绪。

## 5. 数据迁移、回滚与后续

Schema 采用只增不删策略：历史 execution 保持 `batch_id`/`batch_sequence` 为 `NULL`，不重建表、不回填
历史业务行。若在路由切换前需要回退代码，可保留这些可空列和部分索引，不删除已提交 execution 或公开投影；
后续新链路扫描会继续忽略无批次身份的历史 file execution。

下一阶段为 1F-6。开始前应保持 1F-4 的批量受理身份、顺序和失败不回滚已提交事实的原则，并为资源恢复与
Callback 增加持久状态、所有权/CAS、未知外部副作用冻结和同步恢复用例；不得因为已有持久扫描入口而宣称
可靠队列或多实例能力已经完成。
