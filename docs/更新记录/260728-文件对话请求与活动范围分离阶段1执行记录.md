# 文件对话请求与活动范围分离阶段 1 执行记录

## 1. 实施内容

新增 `app/services/chat/domain/document_scope.py`，在不依赖 Flask、SQLite、AnythingLLM 或网络
库的前提下实现：

- `ChatRequestedFile`；
- `ChatScopeRevision`；
- `ChatScopeHead`；
- `ChatScopeDecision`；
- `automatic_initial`、`explicit`、`active_scope_reuse` 三种选择模式；
- 根据事务内 session/head 事实选择范围的 `decide_chat_document_scope()` 纯函数；
- 严格内部 Schema v1 往返；
- 重复业务文件名、文档引用和规范化远端位置门禁。

已有 session 缺失 Scope Head 时明确失败关闭，禁止扫描知识库或读取 Workspace bindings
猜测活动范围。
