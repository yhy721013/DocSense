# 废弃运行时空目录停止预创建执行记录

## 1. 改造目标

停止在加载 Core Settings 时无条件创建以下三个已退出当前正式生产组合根的空目录：

- `${DOCSENSE_RUNTIME_DIR}/llm_downloads`；
- `${DOCSENSE_RUNTIME_DIR}/ocr_markdown`；
- `${DOCSENSE_RUNTIME_DIR}/mineru_markdown`。

文件下载继续由任务私有目录承载，OCR/MinerU 继续由共享 DocumentProcessing Artifact 和物化目录
管理。本次不修改 Legacy Office 的 `office_conversion/jobs`，不迁移或自动删除既有运行数据。

## 2. 契约与范围

- 未新增、删除或修改 HTTP 路由、请求参数、响应字段、状态码、Header、Callback、SSE 或 WebSocket
  语义；
- `docs/接口文档/` 保持只读；阶段 0 已记录 7 个文件的 SHA-256；
- 不运行 `run.py`，不访问 AnythingLLM、MinerU、OCR、LibreOffice 等后台服务；
- 保留内部路径值和旧兼容函数，只删除启动期目录创建副作用；
- 历史更新记录、历史计划和历史诊断中的路径文字保持原样，不篡改当时事实。
