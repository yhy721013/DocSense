## 7. 1B 开工前契约细节确认结果

### CONTRACT-1：混合 params 数组

当前 `_get_params` 会从混合数组中过滤非对象元素，并继续处理剩余对象；接口文档只描述“对象数组”，没有把这一容错行为定义为公开承诺。

**已确认**：只要 `params` 出现任意非对象元素，即把整次 HTTP 请求或 WebSocket 消息判定为参数错误，不过滤后继续处理。HTTP 返回既有 400 单字段错误体；WebSocket 返回既有 error 消息并保持连接。该目标在波次 1B 实现。

### CONTRACT-2：目标收到显式 action 后的处理

**已确认**：收到显式 action 时拒绝整条消息，沿用既有 `{type: "error", message: String}` 错误结构，不发送 ack，并保持 WebSocket 连接。具体错误文字只说明原因，不冻结为稳定枚举值。该目标在波次 1B 实现。
