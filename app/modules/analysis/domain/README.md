# Analysis Domain

本层只表达文件分析的业务规则和不可变输入输出约束，不启动任务、不访问数据库、不读写
文件、不发起网络请求，也不决定 Flask 路由响应。

阶段 1F-1 固定以下边界：

1. 领域树、有限候选召回和分类保护只接受调用方传入的数据，不能读取环境变量或遗留
   Service；
2. Prompt、范围和结果映射保持原有算法、默认值和文本输出，迁移期间不做优化或策略调整；
3. 回调载荷构造只产生字典快照，不执行 HTTP 回调；
4. 领域树与召回索引可使用进程内受控缓存及锁保护既有并发安全语义，但不得据此声称具备
   多实例缓存一致性；
5. Domain 禁止导入 Flask、SQLite、HTTP Client、\`fitz\`、\`app.services\` 和
   \`app.integrations\`。

阶段 1F-2 新增的 `task_inputs.py` 只负责受理期 JSON 深冻结、有效范围和策略快照、内部
`AnalysisTaskInputV1` 不变量；它不生成 TaskId、不读取环境变量，也不访问文件、网络或数据库。

旧 \`app.services.*\` 模块仅作为兼容导出层，不能再成为本层的依赖来源。
