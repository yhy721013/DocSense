# 调试模板目录说明

本目录保存调试蓝图渲染的页面模板，便于开发阶段观察回调和文件对话状态。它们不参与生产文件对话流的执行，也不持有数据库或 AnythingLLM 连接。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `chat.html` | 文件对话调试页面，消费调试蓝图提供的本地预览数据。 |
| `callback.html` | 回调调试页面。 |

## 工作流程

`blueprints/debug.py` 调用 `services/utils/chat_debug_preview.py` 读取本地权威数据，再渲染 `chat.html`。页面用于排查会话、消息、运行、租约和清理任务的状态，不应直接调用或改写 AnythingLLM 资源。

## 维护规则

- 页面显示字段应与调试路由一致，避免加入新的生产接口字段。
- 不得在页面脚本中保存密钥、远端资源引用或内部运行标识用于对外调用。
