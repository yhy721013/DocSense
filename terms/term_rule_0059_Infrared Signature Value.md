# 红外特征值

## 字段定位

- **标准中文字段**：红外特征值
- **标准英文字段**：Infrared Signature Value
- **所属分类**：战技指标
- **标准单位**：dB
- **输出格式**：[数值] dB

## 定义

在规定红外波段、观测角与环境条件下，舰船本体及排气等辐射源的红外辐射量化值（辐射强度或光谱辐射亮度）。

## 可命中的非标准表述 / 别名

- 红外辐射值
- 红外特征
- 红外信号强度
- 热特征值

## 抽取与标准化规则

当原文出现本卡片中的标准字段、英文术语、缩写、非标准表述，或语义上描述同一指标时，应将其归一到标准字段 **红外特征值**。

- 如果原文给出了字段值，应按本规则的标准单位和输出格式进行标准化。
- 最终输出必须包含标准单位“dB”，数值与单位之间使用一个半角空格，禁止只输出纯数字。
- 多个并列值时，每个值都必须分别携带标准单位；数值范围只在整个范围末尾携带一次标准单位。
- 如果原文没有明确给出该字段值，返回空字符串，不要根据常识补全。
- 如果多个字段规则均可能匹配，应优先选择别名、定义、单位和样例同时匹配的一条。
